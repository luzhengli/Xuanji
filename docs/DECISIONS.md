## 2026-11-12 一期闭环跑通真实一轮时的取舍

- 人定（2026-11-11 下达的目标）。原话摘要：“璇玑一期闭环跑通真实一轮：内核 + 接单程序 + xj，从 `xj goal` 到 `xj answer accept`，中间由 Claude Code 无界面执行，人不打开任何 Agent 会话。”“真实一轮用 `--model claude-haiku-5-5` 跑小目标，省周额度；周用量读数超过 60% 就停下来写交接。”“先问：……删除或重建账本表”。
- Agent 定，可逆：**领活即落账**。`POST /runs/claim` 在同一事务里挑任务、落 `run.claimed`、按计数器签发 `RN-n` 并返回；`at` 和 `source_id` 由接单程序带来，内核仍不读时钟。理由：原先“先领再发事件”两步之间有空档，两个接单程序可能领到同一件；编号由归并签发，重放一致。接单程序不再自己发 `run.claimed`。
- Agent 定，可逆：**关联表 `event_refs(ref, seq)` 是投影**，随 `rebuild()` 清空重建，不动事件表。归并时回写事件签发和涉及的编号（`about`、`task_id`、`run_id`、`card_id` 及卡片所属任务）；挂到任务上时连带挂到它的目标。`xj why` 不再用 `payload LIKE` 模糊匹配。
- Agent 定，可逆：**`failed` 的退避用定时器表达**：第 1、2 次失败分别隔 1 分钟、5 分钟（任务转“等世界”加定时器，到点回队列），连续第 3 次转受阻并出决策卡；任何非 `failed` 回执或人解除受阻都把计数清零。理由：调度不必读时钟，退避和 `waiting` 共用同一套定时器。
